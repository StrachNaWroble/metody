# Metody Programowania (OCaml)

Materiały, zadania i projekty z przedmiotu **Metody Programowania** realizowane w języku **OCaml**.

## Zawartość repozytorium

- **calc** – prosty interpreter kalkulatora wyrażeń arytmetycznych
- **fun** – interpreter prostego języka funkcyjnego, testy i zadania
- **LET** – implementacja języka z wiązaniami `let`
- **while** / **while-wyklad** – interpreter języka imperatywnego While, transformacje, optymalizacje i przykłady
- **LISTA10** – maszyna stosowa / akumulatorowa (`calc_acc`, `calc_6809`, `emu6809`)
- **lista11** – rozszerzenia kalkulatora (`calc_if`, `calc_fun`, `calc_opt`)
- **l12** – `tcalc_simple` (kalkulator z typami)
- **tcalc_infer** – inferencja typów
- **tcalc_poly** – system typów polimorficznych
- **prac3** – pracownia programistyczna 3
- **QBF** – algorytm dla kwantyfikowanych formuł Boole'a
- **Listy zadań** – rozwiązania zadań i listy ćwiczeniowe
